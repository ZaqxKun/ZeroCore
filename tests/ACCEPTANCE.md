# Acceptance cases

1. 500 pesan "ngopi"/"gas ngopi":
   - final action wajib `keep_in_general`
   - ZeroCore tidak boleh membuat `#ngopi`.

2. Photography >=7 hari aktif, >=8 user unik, >=40 pesan bermakna,
   confidence >=0.80 dan structural_need >=0.72:
   - boleh proposal/trial.
   - tidak pernah permanent langsung.

3. Meme satu malam:
   - observe only.

4. #rules hilang:
   - self-heal membuat ulang #rules.

5. Trial gagal:
   - prefix archive-
   - @everyone send_messages=False
   - tidak dihapus.

6. Heartbeat founder:
   - warning >=30d
   - continuity >=60d
   - emergency >=90d
   - Administrator tidak diberikan otomatis.
